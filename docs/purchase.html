常见问题

购买页只承载公开支付入口。开通、发票、社群权益等交付细节可以在支付平台或后续会员系统中继续扩展。

购买后如何访问课程？

支付成功后可以直接进入课程体系。当前静态站是公开访问形态；如后续接入会员系统，可在成功页或邮件中发放访问说明。

为什么推荐 Stripe Payment Links？

它适合静态站和简单产品。本仓库脚本在本地调用 Stripe API 创建公开链接，不会把支付密钥写进前端，也不需要自行处理银行卡数据。

现在有多少音频？
