多重世界诠释 vs 哥本哈根：分裂的宇宙，还是坍缩的现实？

“在某种意义上，多世界是正确的——只有一个世界。但它被量子纠缠分裂成无数份。” —— 大卫·华莱士，《涌现的多重世界》

🎯 本课目标

  1. 区别哥本哈根诠释、多世界诠释（MWI）和退相干历史——各自的优势与代价
  2. 理解为什么”多世界”是最简洁（但心理最具挑战）的量子诠释
  3. 用”尤金·维格纳的朋友”悖论理解观测者在量子力学中的尴尬地位
  4. 追问：如果MWI正确，这对”宇宙是模拟的”意味着什么？

一、哥本哈根诠释——标准教科书版本

1.1 三句话总结

1. 波函数ψ是完整的——没有隐变量
2. 测量时ψ坍缩成一个确定结果
3. 测量结果的概率 = |ψ|²（玻恩定则）

1.2 优点与代价

优点 代价
最简单——教科书直接教这个 “观测者”特殊——为什么观测导致坍缩？
与所有实验一致（只要不问”什么是测量”） 测量vs非测量的界限在哪？
不引入额外实体 “坍缩”本身不是薛定谔方程的演化——它是突然的、非幺正的

核心尴尬：哥本哈根诠释用了两种不同的动力学：大多数时候用薛定谔方程（光滑、连续、幺正），但一测量就用”坍缩”（突然、随机、不可逆）。一个理论有两个互相矛盾的演化规则——这不优雅。

二、多世界诠释（MWI）——没有坍缩的量子力学

2.1 休·埃弗雷特三世（1957）

1957年，普林斯顿博士生休·埃弗雷特在他的博士论文中提出了一个激进的想法：

「坍缩不存在。波函数永不坍缩。

当一个量子系统与环境相互作用时，
整个宇宙的波函数分裂成不同的「分支」——
每个分支对应一个可能的测量结果。

我们只体验其中一个分支，因此「感觉」
好像波函数坍缩了——但实际上宇宙一直在分裂。」

2.2 MWI的核心要素

要素 解释
坍塌不存在 波函数严格服从薛定谔方程——只有一种演化规则
退相干=分支 系统和环境的纠缠导致不同结果”脱离”—形成不可沟通的世界
所有结果都发生 薛定谔的猫：一个世界中猫活着，另一个世界中猫死了
概率是幻觉 “我觉得只有10%的概率”是因为在90%的”我”中，结果不同

2.3 分支的多少？

每次量子事件都会分裂宇宙吗？

保守估计 极端估计
每次”测量”分裂 每次量子相互作用都分裂
宇宙每天分裂~10⁵次 宇宙每秒分裂~10⁴⁰次

如果MWI正确且每个量子交互都分支，宇宙”分支数”的增长率是双指数的——比宇宙中的原子数增长还快。

三、退相干历史——“没有坍缩，不需要多世界”的第三条路

3.1 退相干（Decoherence）

1980-1990年代，泽、朱雷克等人完善了退相干理论：

过程 描述
量子系统+环境 系统与环境纠缠
叠加态泄露到环境 环境携带了”系统是0还是1”的信息
局部系统消相干 从系统内部看，叠加态消失了
没有坍缩 整个宇宙的波函数依然是叠加的

3.2 三条路对比

哥本哈根 MWI 退相干历史
有坍缩？ ✓ 物理坍缩 ✗ ✗
所有结果都发生？ ✗ ✓ ✓ 但”退相干”使它们不交互
主观概率有意义？ ✓ ✗（所有都发生→概率无用） ✓ 概率来自”我们只在一个分支”
观测者特殊？ ✓ ✗ ✗
分支数的增长 n/a 指数到双指数爆炸 有限（取决于系统的可区分性）

四、维格纳的朋友——观测者链的尴尬

4.1 1961年的思想实验

尤金·维格纳（1963年诺奖得主）设想：

            ┌──────────┐
            │ 维格纳   │ ← 在外面，可以打开实验室
            └────┬─────┘
       ┌────────┴────────┐
       │                 │
  ┌────┴─────┐    ┌──────┴──────┐
  │  朋友    │    │ 坍缩的猫？  │
  │（观测者）│    │ 叠加的猫？  │
  └──────────┘    └─────────────┘

朋友测量了猫（猫是死是活），但维格纳没看朋友的笔记本。
谁在”看” 朋友的波函数 猫的波函数
没人看 朋友+猫叠加 猫叠加（半死半活）
朋友看猫 朋友看到结果→朋友分支 猫坍缩？还是朋友也叠加？
维格纳看朋友 ？ ？

悖论：维格纳说——如果猫已经坍缩（朋友看到了），那维格纳不需要”再次坍缩”猫。但量子力学说整个系统演化是幺正的——在维格纳”看朋友”之前，整个朋友+猫系统应该处于叠加态。

这意味着：维格纳认为”朋友看到了确定的猫”的事实在维格纳看来不是事实，直到维格纳自己也观察朋友。

五、如果多世界是对的——对模拟假说的影响

5.1 “分支宇宙”的工程成本

如果MWI正确 模拟假说的问题
宇宙每秒分支10⁴⁰次 需要10⁴⁰倍的算力？
每个分支都”同样真实” 模拟需要计算所有分支？
分支永不合并 存储需求指数爆炸

巨大矛盾：如果宇宙是模拟的，MWI意味着计算资源必须能处理天文数字的分支数。这只有在”基座现实”有近乎无限的计算资源时才是可行的——但这与计算机模拟的常规假设矛盾。

5.2 可能解决矛盾的三种方案

方案 内容
A. MWI是错的——只有坍缩（哥本哈根） 不需要计算所有分支
B. 分支不会真的”计算”——它们只是波函数的纯数学分支 分支是免费的——不需要额外计算
C. 基座现实的计算资源确实无限 这就不是”模拟”了，是”现实”

关键：方案B是MWI的主流解释。分支不是物理上”创造新宇宙”——波函数一直就是一个整体，我们只是把它的不同”切片”解释为”不同世界”。在数学上，分支是免费的——不需要额外算力。

练习一：诠释区分（概念型）

下面五个陈述中，哪些是哥本哈根？哪些是MWI？

A. 波函数在测量时坍缩 B. 测量结果是唯一的——其他可能性不发生 C. 所有测量结果都在不同的分支中发生 D. 观测者在量子力学中具有特殊地位 E. 坍缩是一个不必要的假设——量子力学只需要薛定谔方程

点击查看参考答案

哥本哈根：A, B, D MWI：C, E

关键区别： - 哥本哈根需要”坍缩”——测量将概率变成确定 - MWI不需要坍缩——所有结果都发生，我们用”分支”解释概率 - 哥本哈根中观测者特殊——但MWI不区分观测者和粒子

练习二：分支数估算（计算型）

假设”每次量子事件产生一个分支”。太阳每秒钟通过核聚变发射约10³⁸个中微子——每个中微子发射是一次量子事件。请问：太阳诞生以来（约46亿年=1.45×10¹⁷秒），MWI产生了多少个分支？

点击查看参考答案

每次量子事件产生一个分支（近似为2个分支） 总事件数 = 10³⁸/秒 × 1.45×10¹⁷秒 ≈ 1.45×10⁵⁵ 个中微子

即太阳的核聚变产生了约10⁵⁵个量子事件。

但分支是总量——每有一个量子事件，所有现有的分支都”再次分裂”。 所以分支总数 = 2^(事件数) ——这是天文数字中的天文数字。

2^(10⁵⁵) ——这个数字无法用通常的记号表示。

这是MWI的主要批评——“分支的实在性”在如此巨大的数字下 变得令人怀疑。但MWI支持者说：分支是数学对象， 不需要”物理存在”——就像Φ没有物理存在一样。

练习三：“维格纳的朋友”的延续（概念型）

2020年，实验物理学家在真实实验中实现了”维格纳的朋友”的简化版：四光子纠缠系统，其中一个光子扮演”朋友”。实验结果是什么？对MWI和哥本哈根的立场意味着什么？

点击查看参考答案

2020年《自然·物理》发表了布鲁克纳团队的实验（Bong et al. 2020）：

设置： - 光子A和B纠缠 - B作为”朋友”——被测量，结果编码在光子C中 - 外部”维格纳”——测量C的状态

结果：维格纳”看到”的C与B的初始推测不一致—— 即”维格纳”和”朋友”对同一事件有不同描述。

这意味着： 1. 哥本哈根不好处理——“谁是真正的观测者？” 2. MWI可以处理——维格纳和朋友在不同分支 3. 退相干历史可以处理——两个历史”退相干”了

实验并未”证明”MWI——但它暴露了哥本哈根诠释 中”观测者”这个概念的模糊性。

练习四：MWI的”概率问题”（分析型）

如果MWI正确，所有结果都发生。但我做实验时我”感觉”到结果是随机的——比如有30%的概率得到0，70%得到1。MWI如何解释这种”主观概率”？

点击查看参考答案

这是MWI最棘手的挑战——称为概率问题。

MWI说：所有结果都发生。但为什么我感觉不同结果有不同的权重？

可能的回答： 1. 分支权重（德威特）：不同分支的”权重”由|ψ|²给出。 “我”的副本在这些分支中的分布是不均匀的—— 所以在70%的”我”中，我看到1。 但问题：为什么我要”在乎”我在哪一分支？ 如果我是一个”清醒的意识”，那一分支就是我一分支—— 无所谓”概率”。

  1. 决策论论证（多伊奇-华莱士）：即使我知道所有结果都发生， 在我做决策时（如赌博），我”应该”按|ψ|²下注—— 因为给定我的环境，这是我”最好的赌注”。 问题：这要求”分支”之间有可比较的规范性。

  2. 自定位不确定性（塞巴斯蒂安斯）：测量前”我”不知道自己 会落入哪一分支——这种不确定性就是”概率”的来源。

至今没有共识。

练习五：你的宇宙选择（综合型）

你个人倾向于哪种诠释？为什么？这个选择如何影响你对”真实”的定义？

点击查看参考答案

这是真正的哲学题——没有标准答案。

倾向哥本哈根： - 理由：简单、教科书、与日常直觉一致 - 代价：“坍缩”是理论的缺陷，不是特征 - 后果：观测者在宇宙中特殊——但为什么特殊？

倾向MWI： - 理由：最简洁——只有薛定谔方程，没有坍缩 - 代价：“无穷多个我”的心理负担 - 后果：概率需要重新定义——所有可能性都真实

倾向退相干历史： - 理由：技术性最成熟——退相干已实验观察 - 代价：不是完整的诠释——还需要补充”解释” - 后果：叠加态在局部消失——但在全局依然存在

大多数工作物理学家采取”安静主义”——不做选择： 量子力学有效，不需要知道”为什么”。

但如果你想彻底理解宇宙本质——这个选择你做不了逃兵。
