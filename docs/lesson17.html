量子信息：量子比特、量子门、量子算法速通

“信息是物理的。” —— Rolf Landauer

🎯 本课目标

  1. 区分经典比特与量子比特，理解振幅、相位和测量
  2. 掌握 Hadamard、Pauli-X、CNOT 等基础量子门的功能
  3. 理解 Grover、Shor 等量子算法为什么能加速
  4. 看懂不可克隆、退相干和量子纠错对模拟宇宙的意义

难度：⭐⭐⭐⭐ 硬核 | 预计学习时间：55分钟 | 前置课程：第4课、第5课、第12课

🖋️ 引言：量子计算不是“很多宇宙一起帮你算”

量子计算最常见的误解是：量子计算机同时尝试所有答案，然后挑出正确答案。这个说法抓住了一点叠加直觉，却漏掉最关键部分：测量只能读出一个结果。如果没有干涉设计，叠加不会自动变成答案。

量子信息的核心语言是振幅。振幅可以相加、相消、纠缠、旋转，最后在测量时给出概率。真正的量子算法，就是精心安排这些振幅，让错误答案消失，让正确答案凸显。

一、量子比特：比 0 和 1 多了相位

1.1 qubit 的状态

经典比特只能是 0 或 1。量子比特可以处于两个基态的叠加，常写成：

量子态 = α·0态 + β·1态
并且 |α|² + |β|² = 1

这里 α、β 是复数振幅。测量得到 0 的概率是 α 的模平方，得到 1 的概率是 β 的模平方。

对象 状态 读出
经典比特 0 或 1 读出不会改变理想状态
概率比特 以某概率为 0 或 1 只是无知混合
量子比特 振幅叠加 测量按概率给出单个结果
多量子比特 可纠缠状态 不能总拆成单个 qubit

叠加不是“偷偷选好了但我们不知道”，而是实验上会产生干涉效应的真实结构。

1.2 相位为什么重要？

如果只看测量概率，相位似乎看不见。但相位会影响后续干涉。

特征 概率混合 量子叠加
是否有相位 没有 有
能否干涉 不能 能
是否由无知造成 是 不是
测量前是否可被门操作利用 很有限 可以
算法加速来源 无 相位干涉

量子算法的艺术，就是把相位变成计算资源。

二、量子门：可逆旋转，而非普通开关

2.1 单量子比特门

量子门必须保持总概率为 1，因此基本上是量子态空间中的旋转或反射。

门 作用直觉 类比
X 门 交换 0态 与 1态 经典 NOT
Z 门 改变 1态相位 相位翻转
H 门 在基态和叠加之间转换 制造干涉入口
S 门 加四分之一圈相位 相位控制
T 门 加八分之一圈相位 通用量子计算关键非 Clifford 门

Hadamard 门尤其重要：它把确定的 0态 变成均匀叠加，也能把某些相位差转回可测概率差。

2.2 双量子比特门与纠缠

单个 qubit 的旋转还不够。要获得量子计算的非经典能力，需要纠缠。CNOT 是最常见的双比特门：控制比特为 1 时，翻转目标比特。

门 输入关系 作用
CNOT 控制 + 目标 条件翻转目标
CZ 控制相位 条件添加相位
SWAP 两个 qubit 交换状态
Toffoli 两控制一目标 可逆经典计算基础
受控旋转 控制 + 相位角 相位估计常用

当控制比特本身处于叠加时，CNOT 会把两个 qubit 纠缠起来。此后它们不再有各自独立状态，只有整体状态。

三、测量：把振幅账本变成一个事实

3.1 测量的特殊性

量子门是可逆的，测量通常不可逆。测量把振幅分布转成一个经典结果，同时破坏许多相位信息。

过程 是否可逆 作用
量子门 是 旋转振幅，保持信息
纠缠 全局可逆 建立非经典相关
退相干 全局可逆、局部不可逆 信息泄露到环境
测量 对观察者不可逆 产生经典结果
重置 不可逆 丢弃旧信息，产热

这就是为什么量子计算通常把测量放到最后，或只在纠错中谨慎测量辅助 qubit。

3.2 不可克隆定理

未知量子态不能被完美复制。这与经典信息完全不同。

信息类型 是否能复制 原因
经典 bit 能 读出不必改变状态
已知量子态 能制备副本 你知道制备程序
未知量子态 不能完美复制 线性量子力学禁止通用克隆
纠缠态的一部分 不能单独复制 会破坏相关结构

不可克隆定理让量子信息更像“不可随便截图的现实”，也让量子密码和量子纠错成为可能。

四、量子算法：快在哪里？

4.1 Grover 搜索

Grover 算法处理无结构搜索。经典搜索 N 个候选需要约 N 次查询；Grover 只需约平方根 N 次查询。

候选数 N 经典查询量级 Grover 查询量级
10^6 10^6 10^3
10^12 10^12 10^6
2^128 2^128 2^64
2^256 2^256 2^128

Grover 不会把指数问题全部变简单，但会把安全参数砍半。因此对对称密码需要加大密钥长度。

4.2 Shor 算法

Shor 算法能在量子计算机上高效分解大整数，威胁 RSA 等公钥密码。

算法 问题 加速类型 关键结构
Deutsch-Jozsa 函数性质判断 示例性指数差异 全局性质
Grover 无结构搜索 平方加速 幅度放大
Shor 整数分解 指数级优势 周期寻找
量子相位估计 本征相位 多算法核心 受控幺正操作
HHL 线性方程 条件性加速 稀疏与读出限制

量子算法强在“结构”。没有可利用结构，叠加只会给你随机测量结果。

五、量子纠错与宇宙信息语法

5.1 退相干是敌人

现实量子计算机的问题不是“会不会叠加”，而是叠加太容易被环境破坏。

错误类型 含义 处理思路
比特翻转 0态 与 1态 被交换 冗余编码检测
相位翻转 相位符号改变 换基检测
退相干 环境获得路径信息 隔离与纠错
泄漏错误 状态跑出计算空间 硬件控制
测量错误 读出不准 重复 syndrome 测量

量子纠错不能复制未知态，而是把一个逻辑 qubit 编码进多个物理 qubit 的纠缠子空间中。

5.2 对模拟假说的意义

量子信息给模拟宇宙提出最硬的约束。

模拟者必须处理 为什么困难
振幅相位 不能只保存概率
纠缠结构 多体状态维度指数增长
测量一致性 结果随机但统计规律精确
不可克隆 不能随便复制未知子系统来省事
量子纠错式全息 信息可能非局部冗余编码

5.3 读懂量子优势的检查清单

判断一个量子方案是否真的有优势，可以问五个问题：它是否有可制备的初态，是否有保持相干的门序列，是否把答案编码进可测概率，是否有错误纠正门槛，是否考虑了读出成本。很多“量子灵感”只停在第一步，看起来有叠加，最后却没有可读答案。

检查项 好迹象 危险信号
初态制备 可重复、可校准 需要指数复杂准备
干涉结构 明确放大正确振幅 只是枚举所有候选
读出 少量测量得到答案 需要读出完整波函数
纠错 错误率低于门槛 忽略退相干
复杂度 总成本仍有优势 把成本藏在输入输出

这张清单同样适用于“量子模拟宇宙”的说法。量子模型可以更自然地表示现实，但它不是免成本通行证。

还有一个经常被忽略的限制：量子优势通常只出现在精心定义的问题上，而不是所有日常任务上。对模拟宇宙而言，这意味着“用量子底层表示量子世界”很自然，但“用量子计算免费跳过所有演化”并不自然。

误区 更准确的说法
qubit 数翻倍就自动指数加速 态空间变大，但可读信息仍受测量限制
叠加等于并行答案表 没有干涉设计就只是随机输出
纠缠越多越好 无结构纠缠可能只是噪声
量子模拟总比经典模拟快 只对匹配结构的问题明显有利

本课结论：量子信息不是经典信息加魔法，而是一套更严格的物理语法。任何严肃的模拟宇宙理论，都必须能解释振幅、纠缠、测量和纠错，而不只是解释 0 和 1。

练习一：测量概率（计算型）

某 qubit 状态振幅满足：α=√3/2，β=1/2。测量得到 0态 和 1态 的概率分别是多少？

点击查看参考答案

概率是振幅模平方。

得到 0态 的概率：(√3/2)^2 = 3/4 = 75%。

得到 1态 的概率：(1/2)^2 = 1/4 = 25%。

总概率 75%+25%=100%，符合归一化条件。

练习二：Grover 加速（计算型）

一个无结构数据库有 10^10 个候选。经典搜索和 Grover 搜索查询量级分别是多少？

点击查看参考答案

经典搜索量级约 10^10 次。

Grover 搜索量级约 √10^10 = 10^5 次。

这是巨大提升，但不是指数问题全部消失；它是平方级加速。

练习三：叠加 vs 概率混合（概念型）

为什么“50% 概率为 0、50% 概率为 1”的经典随机 bit 不等于均匀叠加 qubit？

点击查看参考答案

经典随机 bit 只是我们不知道它实际是 0 还是 1，没有相位，也不能干涉。

均匀叠加 qubit 有振幅和相位。后续量子门可以让不同路径相加或相消，产生经典概率混合没有的实验结果。

干涉能力是关键差别。

练习四：不可克隆的影响（分析型）

如果未知量子态可以被完美复制，会对量子密码和量子测量产生什么影响？

点击查看参考答案

量子密码会受到严重破坏，因为窃听者可以复制传输中的未知量子态，保留副本后再慢慢测量，不必扰动原系统。

测量理论也会改变，因为你可以复制大量副本，用不同基测量来重建未知态。

不可克隆定理正是量子信息与经典信息不同的基础约束。

练习五：量子模拟宇宙（综合型）

如果模拟者只保存每个粒子的经典位置和速度，而不保存量子振幅与纠缠，会在哪些实验中露馅？

点击查看参考答案

可能在双缝干涉、贝尔不等式实验、量子隐形传态、量子计算加速、超导 qubit 干涉实验中露馅。

这些实验依赖相位、叠加和纠缠。只保存经典位置速度，无法产生正确的统计关联和干涉图样。

因此模拟宇宙若要匹配现实，必须至少在可实验范围内保存量子信息结构。
