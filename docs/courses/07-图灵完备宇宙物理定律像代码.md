## 一、图灵完备：三个字改变世界

### 1.1 什么是图灵完备

艾伦·图灵（1936）：任何物理上可计算的问题，都可以被一台通用图灵机计算。

| 系统 | 是否图灵完备 | 说明 |
|------|------------|------|
| 通用图灵机 | ✓（定义） | 可以模拟任何图灵机 |
| Python / C / JS | ✓ | 可以写任何算法 |
| Excel | ✓（意外地） | 可以用公式实现图灵机 |
| Magic: The Gathering | ✓ | 卡牌游戏居然能计算 |
| 康威生命游戏 | ✓ | 2D细胞自动机 |
| HTML+CSS | ✓ | 甚至不需要JS |

### 1.2 关键性质

**如果你有一个图灵完备的系统，你可以用它：**
- 执行任意算法
- 模拟任何数字计算机
- 在原则上解决任何可计算的问题

| 性质 | 含义 |
|------|------|
| 通用性 | 所有图灵完备系统等价——可以互相模拟 |
| 不可判定性 | 停机问题等无法算法化解决 |
| 可编程性 | 你可以在上面"写程序" |

## 二、物理定律是图灵完备的吗？

### 2.1 丘奇-图灵-多伊奇论题

牛津物理学家大卫·多伊奇（1985）将丘奇-图灵论题扩展到物理世界：

<pre>
「每个有限可实现的物理系统都可以被
  一台通用量子计算机完美模拟。」

更简洁的表述：
  物理宇宙 = 量子图灵机
</pre>

| 版本 | 主张 | 状态 |
|------|------|------|
| 丘奇-图灵论题（1936） | 所有有效计算方法等价于图灵机 | 广泛接受 |
| 物理丘奇-图灵论题 | 物理世界中所有过程都可被图灵机模拟 | 有争议 |
| 多伊奇论题（1985） | 物理宇宙=量子图灵机 | 活跃研究 |

### 2.2 支持物理定律=计算的证据

| 证据 | 细节 |
|------|------|
| **量子电动力学（QED）** | 费曼路径积分→无限求和→原则上可模拟 |
| **量子色动力学（QCD）** | 格点QCD→离散化时空→可计算 |
| **广义相对论** | 数值相对论→黑洞合并→可计算 |
| **标准模型** | 全部四个基本力都已成功在计算机上模拟 |
| **量子计算理论** | 量子电路模型→多项式效率→物理可行 |

> **关键观察**：目前为止，所有已知的物理定律都可以在计算机上模拟。没有人发现"不可计算的"物理过程——虽然我们也不知道为什么。

### 2.3 如果物理定律不是图灵完备的

如果发现了"超图灵"物理过程（hypercomputation）——即可以解决停机问题的物理过程——那将是一场革命：

| 可能性 | 含义 |
|--------|------|
| 存在超图灵过程 | "我们的宇宙"无法在"基座宇宙"的计算机上模拟 |
| 不存在超图灵过程 | "我们的宇宙"可以在计算资源足够的情况下完全模拟 |
| 目前证据 | 没有发现任何计算上不可约化的物理过程 |

## 三、康威的生命游戏：最简单的"宇宙"

### 3.1 四条规则，一个世界

1970年，约翰·康威发明了生命游戏（Game of Life）：

| 规则 | 条件 | 结果 |
|------|------|------|
| 规则1 | 活细胞邻居<2 | 死（孤独） |
| 规则2 | 活细胞邻居=2或3 | 活（存活） |
| 规则3 | 活细胞邻居>3 | 死（拥挤） |
| 规则4 | 死细胞邻居=3 | 生（繁殖） |

仅此四条规则，在一个2D网格上运行。

### 3.2 从简单规则到复杂行为

| 涌现结构 | 行为 | 类比 |
|---------|------|------|
| 滑翔机（Glider） | 对角线匀速移动 | "粒子" |
| 滑翔机枪（Gosper gun） | 周期发射滑翔机 | "放射源" |
| 反射器/复制器 | 改变/复制信号 | "逻辑门" |
| 通用图灵机 | 在生命游戏中构建 | "计算机" |
| 自我复制器 | 复制自身 | "生命" |

> **震撼事实**：康威生命游戏是图灵完备的。这意味着**理论上你可以在生命游戏里运行Windows**——虽然极其低效。

### 3.3 生命游戏对模拟假说的意义

| 生命游戏特性 | 宇宙类比 |
|------------|---------|
| 4条简单规则 | 一组基本物理定律 |
| 无限复杂度涌现 | 从基本粒子到星系到生命 |
| 图灵完备 | 可以计算任何东西 |
| 确定性但在宏观不可预测 | 拉普拉斯妖不可能 |
| "生命"可以在其中自组织 | 生命可能自然涌现 |

> **核心启示**："简单规则产生丰富世界"不是科幻——它已经在数学上被证明了。我们的宇宙可能只是比生命游戏多几条规则（17种基本粒子的交互规则），但本质上遵循相同的模式。

| 约翰·惠勒（1989） | "it from bit"——物质来自信息 |

### 4.2 "it from bit"——惠勒的洞见

约翰·阿奇博尔德·惠勒是20世纪最伟大的物理学家之一（费曼的导师、"黑洞"概念的命名者）。他晚年提出：

<pre>
「每个物理量、每一个「它」——粒子、力场、
  时空连续体本身——都将它的功能、意义、
  存在完全归功于——即使在某些情况下是间接的——
  设备对问题的回答所给出的答案。
  是的或否的答案。二进制选择——比特。」

「简而言之：it from bit——万物来自比特。」
</pre>

| 概念 | 传统物理学 | 数字物理学 |
|------|----------|-----------|
| 物质 | 基本实体 | 信息的一种表现 |
| 空间 | 连续统 | 离散的"像素" |
| 时间 | 连续流动 | 离散的"步骤" |
| 物理定律 | 数学方程 | 计算规则/算法 |

### 4.3 数字物理学的三个测试

| 测试 | 如果是模拟，预测 | 如果是"自然的" |
|------|---------------|-------------|
| **格点各向异性** | 极高能量下可能检测到 | 连续统——没有偏好方向 |
| **GZK截断效应** | 宇宙线能量被格点截止 | 只有CMB光子散射截止 |
| **量子引力离散性** | 时空在普朗克尺度离散 | 可能连续（弦论）或离散（圈量子引力） |

## 🧪 本课练习

### 练习一：图灵完备测试（概念型）

假设你想测试"物理宇宙是否图灵完备"。请设计一个关键实验——你需要物理系统展示什么能力？

<details>
<summary>点击查看参考答案</summary>

判断一个系统是否图灵完备，需要它能执行：
1. 条件分支（if...then...else）
2. 无限循环或递归（while/recursion）
3. 可读写内存（存储中间结果）

对于物理宇宙，证据包括：
- 条件分支：相变、阈值行为（如核聚变的温度阈值）
- 循环：周期性的物理过程（轨道、振荡）
- 内存：物质/能量可以存储信息（全息原理）

如果有人构建了一个"物理逻辑门"——一个能用物理过程
实现NAND门（通用逻辑门）的装置——那就直接证明了
物理宇宙的图灵完备性。事实上，任何数字电路都是这样的证据。
</details>

### 练习二：生命游戏实验（计算型）

在康威生命游戏中，"滑翔机"每4代向右下移动一格。如果一个滑翔机枪每30代发射一个滑翔机，请计算：1亿代后，最远的滑翔机距离枪口多远？

<details>
<summary>点击查看参考答案</summary>

滑翔机速度 = 1格/4代 = 0.25格/代

第一个滑翔机在30代时发射，在1亿代时已经走了：
(1亿 - 30) × 0.25 = 24,999,992.5格

但最后一个滑翔机在约1亿 - 30代时发射，走了约7.5格。
总"滑翔机云"长度 ≈ 2500万格。

这在工程上意味着：即使最简单的规则，
长时间演化后也能产生巨大的空间结构。

类比到宇宙——138亿年的演化时间足以让
"简单规则"产生无比复杂的结构。
</details>

### 练习三："it from bit"的计算（计算型）

如果全息原理成立，且可观测宇宙的信息存储在球面上，每个普朗克面积（lₚ²=2.6×10⁻⁷⁰ m²）存储1比特，请计算：整个可观测宇宙的信息是否可以被一台"基座现实"的计算机存储？假设这台计算机的存储极限是10¹²²比特。

<details>
<summary>点击查看参考答案</summary>

球面面积 A = 4πR²，R=4.4×10²⁶m
A = 4π × (4.4×10²⁶)² = 2.43×10⁵⁴ m²

每普朗克面积存储1比特：
比特数 = 2.43×10⁵⁴ / 2.6×10⁻⁷⁰ = 9.3×10¹²³ bits

但宇宙的总信息量（贝肯斯坦界限）≈ 10¹²² bits。

差异在于：宇宙的球面边界不等于宇宙半径²×4π——
时空在宇宙尺度是弯曲的（不是平坦3D空间）。

关键结论：如果基座计算机有10¹²²比特的存储能力，
它理论上可以存储我们的整个宇宙的全部信息。
更可能的是——它只需要存储"对我们的宇宙可见"的信息，
这远少于10¹²²比特。
</details>

### 练习四：数字 vs 连续（哲学型）

物理学家无法在实验上区分"物理是真的连续的"还是"物理只是离散得极小以至于无法分辨"。请论证：这对"宇宙是模拟的"假说为什么至关重要？

<details>
<summary>点击查看参考答案</summary>

如果宇宙是真正连续的：
- 空间中有无限多个"点"
- 每个"点"需要无限精度来描述
- 模拟无限精度的连续体需要无限的计算资源
- → "模拟宇宙"不可能（即便是基座现实）

如果宇宙是离散的（在某个极小尺度上）：
- 空间中有有限个（虽然极其多）像素
- 每个像素只需有限精度
- 有限的计算资源可以模拟
- → "模拟宇宙"原则上是可能的

普朗克长度（1.6×10⁻³⁵米）恰好提供了一个自然的最小尺度——
这恰好是量子力学和广义相对论的交汇点。

因此："宇宙恰好提供了离散性（普朗克尺度）"可以被解读为：
要么这是物理的深层真理（自然就是离散的），
要么这是模拟系统的"分辨率上限"。

目前实验无法区分。
</details>

### 练习五：设计你自己的小宇宙（综合型）

设计一个"最小可行宇宙"——一组最简单的规则，使得在足够长的运行后能产生至少一种"有趣"的自组织结构。规则数量不超过5条。描述这个系统。

<details>
<summary>点击查看参考答案</summary>

示例：一个3D版本的简化生命游戏。

规则：
1. 每个格点是0（空）或1（有粒子）
2. 如果邻域中粒子数=2→状态不变
3. 如果邻域中粒子数=3→变为1
4. 如果邻域中粒子数≠2且≠3→变为0
5. 每10代随机在1个格点注入1（模拟"能量输入"）

运行10万代后可能出现：
- 稳定的振荡结构（"原子"）
- 自复制结构（"生命"的萌芽）
- 传播的波动（"光"）

关键是：仅4条确定规则+1条随机输入，
就可能产生不可预测的涌现行为。

这反过来告诉我们：我们的宇宙不需要
"复杂的设计"——只需要正确的初始条件和基本规则。
而"精密调校"（第6课）可能就是那组正确的参数。
</details>
