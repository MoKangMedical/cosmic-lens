## 一、暗能量——科学史上最意外的发现

### 1.1 1998年：一个"错误"改变宇宙学

两个独立的超新星巡天团队预期发现宇宙在减速膨胀——结果恰好相反：

| 团队 | 领导者 | 发现 |
|------|--------|------|
| 高红移超新星巡天(HSST) | 布莱恩·施密特 | Ia型超新星比预期暗→宇宙在加速膨胀 |
| 超新星宇宙学项目(SCP) | 索尔·珀尔马特、亚当·里斯 | 独立证实——宇宙在加速 |

> 2011年，珀尔马特、施密特和里斯因"发现宇宙加速膨胀"获诺贝尔物理学奖。

### 1.2 宇宙的成分构成

| 成分 | 占比 | 性质 |
|------|------|------|
| 暗能量 | 68.3% | 加速膨胀 |
| 暗物质 | 26.8% | 引力但不发光 |
| 普通物质（原子） | 4.9% | 我们、恒星、星系 |
| - 其中我们能"看到"的 | ~0.5% | 发光的恒星 |
| - 气体和尘埃 | ~4.4% | 不可见但可探测 |

> 我们（原子物质+可见恒星）只占宇宙的约5%。

## 二、暗能量是什么？——三个方案

| 候选 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| 宇宙学常数Λ | 空间本身的能量密度，恒定不变，w = -1 | 最简单，与观测一致 | "为什么这么小？"（10¹²⁰问题） |
| 精质(Quintessence) | 动态的标量场，w > -1，随时间变化 | 可解释"巧合问题" | "这个场是什么？" |
| 修正引力 | 广义相对论在大尺度下需要修正（f(R), DGP等） | 不需要"暗能量"，修正爱因斯坦方程 | 在太阳系尺度回归GR很困难 |

### 暗能量必要参数：w = P/ρ

| w的值 | 含义 |
|-------|------|
| w = -1 | 宇宙学常数Λ |
| w ≈ -1.03 ± 0.03 | 当前最佳观测（DESI 2024） |
| w > -1 | 精质型暗能量 |
| w < -1 | 幻影能量——"大撕裂"可能 |

## 三、哈勃张力——暗能量的新麻烦

| 测量方法 | 哈勃常数H₀ |
|---------|----------|
| 宇宙微波背景(Planck卫星) | 67.4 ± 0.5 km/s/Mpc |
| Ia型超新星+造父变星 | 73.0 ± 1.0 km/s/Mpc |
| 差异 | ~5σ——不可能纯属巧合 |

> 如果两个方向都是正确的，那么"标准ΛCDM模型"缺了什么——可能是暗能量随时间变化的最强暗示。

## 四、宇宙的最终命运

| 如果暗能量是 | 宇宙命运 | 时间尺度 |
|-----------|---------|---------|
| 稳定的Λ(w=-1) | 永远加速→"大冻结"(Big Freeze) | ∞ |
| 慢慢增强的Λ(w逐渐<-1) | "大撕裂"(Big Rip)——星系、行星、原子被撕裂 | ~220亿年 |
| 精质转弱变化 | "大坍缩"(Big Crunch) | 未知 |
| 真空衰变 | 量子隧穿到更稳定真空态→物理定律改变 | 任意时刻 |

> **当前共识**：我们的数据最支持"大冻结"——宇宙将永远膨胀、冷却、变暗。最后黑矮星和黑洞也将蒸发。

## 五、模拟假说视角：暗能量是"系统冷却"

### 暗能量与硬件的类比

| 宇宙现象 | 计算类比 |
|---------|---------|
| 暗能量加速膨胀 | CPU散热——系统在降温/降低计算密度 |
| 宇宙在"稀释" | 内存压力降低——给未来的计算留空间 |
| 哈勃张力 | 系统时钟的两个计数器不同步 |
| "刚好能产生星系"的Λ | 调试好的膨胀率——不太快也不太慢 |

> **逆天工程猜想**：如果宇宙是一个正运行的模拟系统，暗能量的"加速"可能不是bug——而是**优化策略**：随着宇宙年龄增大、结构越来越复杂，用加速膨胀降低整体计算密度，避免热力学极限。

### 练习二："大冻结"宇宙的时间线（计算型）

按大冻结场景，用对数时间线标记以下里程碑：

太阳寿命(50亿年)、最后一颗恒星诞生(10¹⁴年)、最后恒星死亡(10¹⁵年)、黑洞时代(10¹⁰⁰年)、光子气体(∞)

<details>
<summary>点击查看参考答案</summary>

```
现在 ──────────────────────────────────────────→∞

0    → 50亿年    → 10¹⁴年   → 10¹⁵年    → 10¹⁰⁰年  →∞
现在    太阳死亡   最后恒星诞生 最后恒星死亡  黑洞蒸发完  光子气体

总结：
- 宇宙的"活力期"（有恒星）只占0→10¹⁵年
- 之后的10¹⁰⁰年全是黑洞时代
- 再之后是永恒的、空无一物的光子气体

换句话说，我们现在生活在宇宙最具活力和复杂性的0.0000000000001%时间里。

</details>

### 练习三：哈勃张力意味着什么？（分析型）

两个独立方法测出的H₀差距5σ（~9%）。这不可能是巧合。请列出三种可能的解释。

<details>
<summary>点击查看参考答案</summary>

1. 系统误差——某个测量有未被发现的偏误。但两个方法
   都经过反复验证，5σ已极强。

2. 新物理——暗能量不是常数Λ，而是随时间变化的精质。
   早期和晚期宇宙的H₀不同是因为暗能量强度变了。

3. 修正引力——广义相对论在宇宙尺度需要修正项。
   早期和晚期宇宙的行为不同→推断出的H₀不同。

4. 额外中微子/暗辐射——早期宇宙有额外的辐射成分，
   可以调和两者。

目前(DESI 2024, ACT 2024)数据更加复杂——新的观测
似乎同时支持修正两边。这可能是当前宇宙学最大谜题。
</details>

### 练习四：暗能量的模拟假说假设（分析型）

如果你是模拟设计者，你在config里设置暗能量参数时，你会考虑什么？

<details>
<summary>点击查看参考答案</summary>

1. 不能太强——宇宙太快膨胀→星系无法形成
2. 不能太弱——宇宙可能坍缩→模拟提前结束
3. 合适的"对冲"：抵消物质引力，但不用太快

4. 最反直觉的动机：**延迟热寂**
   宇宙=一个计算过程。如果所有物质聚在一起，
   引力坍缩可能造成计算热点（类比CPU过热）。
   慢慢散开会降低总体信息处理密度→平稳运行。

5. 让"晚期宇宙"依然有可利用的自由能——
   避免全部物质变成黑洞然后蒸发。适度的暗能量
   让宇宙"收敛到一个低温均匀状态"而非"灾难性崩溃"。

这当然是脑洞——但它在工程上逻辑自洽。
</details>

### 练习五：如果暗能量=0会怎样？（综合型）

假设爱因斯坦的"最大错误"是对的——暗能量根本不存在（Λ=0）。宇宙现在会是什么样？

<details>
<summary>点击查看参考答案</summary>

如果Λ=0，宇宙膨胀由物质密度决定：
- 如果Ω_m > 1（超临界）：宇宙已开始坍缩
- 如果Ω_m = 1（平坦）：膨胀渐趋稳定
- 如果Ω_m < 1（亚临界）：继续膨胀但减速

当前观测：Ω_m ≈ 0.31 → 没有Λ的话应该是亚临界宇宙，
继续膨胀但永远减速。

关键差异：
- 观测加速膨胀 → 需要Λ ≈ 0.69
- 没有Λ → 超新星应该比观测到的更亮，
  而不是更暗

1998年的发现就是"比预期更暗的超新星"——
如果Λ=0，这个结果不会出现。

爱因斯坦在1917年引入Λ是为了获得静态宇宙。
他说那是他的"最大错误"。但2011年诺奖说——
Λ是对的，只是原因不同。物理史充满了这种讽刺。
</details>
