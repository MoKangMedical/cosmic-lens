## 一、信息在物理学中是什么

### 1.1 物理信息≠语义信息

| | 日常"信息" | 物理"信息" |
|------|----------|-----------|
| 定义 | "我知道猫在垫子上" | 完全描述一个系统微状态需要的比特数 |
| 量度 | 语义内容 | 熵（S = k log W） |
| 守恒？ | 否——我可忘掉 | **是——量子力学要求信息守恒** |

### 1.2 量子力学的信息守恒

薛定谔方程是线性的、幺正的（unitary）：

```
|ψ(t₂)⟩ = U(t₁,t₂) |ψ(t₁)⟩

U 是幺正算符 → 信息不丢失 → 可以从结果逆推原因
```

| 性质 | 含义 |
|------|------|
| 幺正性(Unitarity) | 量子演化是可逆的——信息守恒 |
| 线性叠加 | 多重可能性共存 |
| 确定性演化 | 给定初始态→唯一终态 |

## 二、霍金1974：量子力学 vs 广义相对论

### 2.1 黑洞的"三毛定理"——经典黑洞丢失信息

| 经典黑洞 | 表现 |
|---------|------|
| 只有三个参数 | 质量M、角动量J、电荷Q |
| 物质掉进去 | 无论是什么（书、恒星、人）→只剩下M/J/Q |
| 信息去哪了？ | **经典回答：丢了。** 霍金1976称之为"信息悖论" |

### 2.2 霍金辐射——黑洞不黑

| 过程 | 描述 |
|------|------|
| 真空中不断产生虚粒子对 | 粒子+反粒子→瞬间出现又湮灭 |
| 在视界处 | 一个被吸入，一个逃逸 |
| 逃逸的粒子 | =霍金辐射，携带能量离开 |
| 净效果 | 黑洞慢慢蒸发 |

| 公式 | 含义 |
|------|------|
| T_H = ħc³/8πGMk | 霍金温度（太阳质量黑洞 ~6×10⁻⁸ K） |
| t_evap ≈ 10⁶⁷(M/M_⊙)³ 年 | 蒸发时间（大黑洞寿命极长） |
| λ_H ≈ 黑洞大小 | 辐射波长≈黑洞大小 |

> 太阳质量黑洞的温度约为6×10⁻⁸ K——比宇宙微波背景(2.7K)还冷得多，所以大质量黑洞当前是净吸收，而非蒸发。

## 三、黑洞信息悖论——四种立场

### 3.1 悖论的核心矛盾

1. 量子力学说：信息必须守恒
2. 霍金1976年说：落入黑洞的信息随霍金辐射丢失了
3. 两者不能同时成立

### 3.2 四种解决方案

| 方案 | 主张 | 代价 |
|------|------|------|
| **信息丢失** | 霍金(1976)：量子力学错了——信息确实会被毁灭 | 放弃量子力学基石 |
| **信息残留** | 黑洞蒸发完后留下一个"裸奇点"——内含所有信息 | 奇异物理 |
| **信息编码** | 霍金辐射中编码了落入物质的信息——但我们读不出来 | 信息理论上在，但实践上找不回 |
| **信息逃逸** | 信息从未跨过视界——被"防火墙"烧毁在表面 | 需改写广义相对论 |

### 3.3 霍金2004年认输

> 2004年7月21日，霍金在都柏林GR17会议上宣布："我错了——信息不会在黑洞中丢失。"

他支付了与普雷斯基尔（约翰·普雷斯基尔）的赌注——一套棒球百科全书。

## 四、全息原理——3D世界是2D投影

### 4.1 贝肯斯坦发现：熵∝面积

1972年，雅各布·贝肯斯坦提出黑洞有熵：

| 公式 | S_BH = kc³A / 4Għ |
|------|-------------------|
| A | 视界面积 |
| k | 玻尔兹曼常数 |

> **关键观察**：黑洞的熵——即它的信息容量——正比于它的**表面积**，而非体积。这反直觉——你在一个盒子里能塞的信息正比于体积，但黑洞的信息正比于面积。

### 4.2 全息原理（'t Hooft 1993, Susskind 1995）

<pre>
「一个D维时空中的所有信息
  等价于编码在它的(D-1)维边界上的信息。」

我们可能生活在一个"全息图"里——
3D空间的现实编码在遥远的2D球面上。
</pre>

| 含义 | 细节 |
|------|------|
| 3D世界可能是"投影" | 就像全息照片的3D影像来自2D胶片 |
| 信息密度有上限 | 每普朗克面积最多1比特 |
| 我们的现实可能是"表面的" | 我们感觉3D——但信息存储在2D边界 |
| AdS/CFT对应 | 弦论中实现了全息原理的精确数学版本 |

## 🧪 本课练习

### 练习一：信息容量计算（计算型）

已知太阳质量黑洞视界半径R_s=3km，普朗克长度l_p=1.6×10⁻³⁵m。估算该黑洞最多能存储多少比特信息（用全息原理）。

<details>
<summary>点击查看参考答案</summary>

贝肯斯坦-霍金公式：S = kc³A/4Għ = A/(4l_p²)

A = 4π(3000m)² = 1.13×10⁸ m²
l_p² = 2.56×10⁻⁷⁰ m²

比特数 = A/(4l_p²) = 1.13×10⁸ / (4 × 2.56×10⁻⁷⁰)
       = 1.13×10⁸ / 1.02×10⁻⁶⁹
       ≈ 1.1×10⁷⁷ bits

对比：地球上所有数据总量≈10²² bits（2025年估计）
→ 一个太阳质量黑洞可存 10⁵⁵ 倍的地球数据！
</details>

### 练习二：蒸发时间（计算型）

计算一个10亿吨重的微型黑洞（M=10⁹ kg）的霍金蒸发时间。t_evap = (5120πG²M³)/ħc⁴

<details>
<summary>点击查看参考答案</summary>

t_evap = 5120π × (6.67×10⁻¹¹)² × (10⁹)³ / (1.05×10⁻³⁴ × (3×10⁸)⁴)
       = 5120π × 4.45×10⁻²¹ × 10²⁷ / (1.05×10⁻³⁴ × 8.1×10³³)
       = 7.16×10¹⁰ / 0.85
       ≈ 8.4×10¹⁰ 秒
       ≈ 2,660 年

即：10亿吨微型黑洞约2660年蒸发完。

对比：太阳质量黑洞蒸发时间 ~ 10⁶⁷年（宇宙年龄的10⁵⁷倍！）
</details>

### 练习三：悖论辨析（概念型）

下面这段话错在哪？
"霍金辐射证明黑洞会蒸发，所以信息终究会回到宇宙中。因此黑洞信息悖论已经解决了。"

<details>
<summary>点击查看参考答案</summary>

问题：霍金1976年的原始论证恰恰是——霍金辐射是**热辐射**，不携带任何信息。

想象烧一本书：热辐射携带能量，但你无法从中还原书的内容。

辩论的核心是，霍金辐射到底：
A. 完全是热的（无信息）→信息确实丢失→悖论成立
B. 有精细的非热关联（编码了信息）→信息从未丢失→悖论可解

2004年霍金认输并支持B。但**如何**编码、编码效率多少，
至今仍是活跃研究。完全解决需要量子引力理论。
</details>

### 练习四：全息宇宙（哲学型）

如果全息原理正确，我们感知的3D世界只是存储在宇宙边界2D表面信息的"投影"。这意味着什么？

<details>
<summary>点击查看参考答案</summary>

可能的影响：

1. 空间是涌现的：空间不是基本现实——它是更基本的
   信息结构的一种"现象"。
2. 我们可能像柏拉图的洞穴囚徒：看到的是"投影阴影"，
   而非真实。
3. 模拟假说获得强大盟友：如果现实已经在信息意义上
   "只有2D"，那模拟3D世界只需要2D信息+投影规则。
   这恰好是计算机渲染3D游戏的方式。
4. 我们不需要模拟整个3D宇宙：只需要2D表面的信息——
   这正是最有效的"模拟优化"。

但注意：全息原理≠我们"真的是"投影。它是一个物理猜想，
尚未完全验证。1997年Maldacena的AdS/CFT是它的最强证据，
但我们的宇宙不是反德西特空间。
</details>

### 练习五：信息守恒与死后世界（综合型）

量子力学说信息守恒。这是否意味着你大脑中的一切信息也将永远持续存在？这能用来论证某种"不朽"吗？

<details>
<summary>点击查看参考答案</summary>

量子力学的"信息守恒"是微观层面的——

微观层面：单电子自旋的方向信息在量子力学中
确实永远不丢失（在孤立系统中）。

宏观层面：复杂系统的信息受制于**热力学第二定律**——
信息可以扩散、分散、与外界纠缠到"实际上不可恢复"。

你的大脑记忆存储在约10¹⁵个突触连接的精确强度中。
当你死后，这些信息扩散到环境中——理论上还存在，
但实际上被稀释到整个世界的量子态中，无法恢复。

全息原理和信息守恒是物理定律，不是灵性承诺。
它们确保的是物理信息的守恒，不是个体意识的延续。

用量子信息守恒来论证死后世界，通常是对
"信息守恒"的过度引申。
</details>
