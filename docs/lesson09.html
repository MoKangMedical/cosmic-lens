二、暗能量是什么？——三个方案

候选 描述 优点 缺点
宇宙学常数Λ 空间本身的能量密度，恒定不变，w = -1 最简单，与观测一致 “为什么这么小？”（10¹²⁰问题）
精质(Quintessence) 动态的标量场，w > -1，随时间变化 可解释”巧合问题” “这个场是什么？”
修正引力 广义相对论在大尺度下需要修正（f(R), DGP等） 不需要”暗能量”，修正爱因斯坦方程 在太阳系尺度回归GR很困难

暗能量必要参数：w = P/ρ

w的值 含义
w = -1 宇宙学常数Λ
w ≈ -1.03 ± 0.03 当前最佳观测（DESI 2024）
w > -1 精质型暗能量
w < -1 幻影能量——“大撕裂”可能

三、哈勃张力——暗能量的新麻烦

测量方法 哈勃常数H₀
宇宙微波背景(Planck卫星) 67.4 ± 0.5 km/s/Mpc
Ia型超新星+造父变星 73.0 ± 1.0 km/s/Mpc
差异 ~5σ——不可能纯属巧合

如果两个方向都是正确的，那么”标准ΛCDM模型”缺了什么——可能是暗能量随时间变化的最强暗示。

四、宇宙的最终命运

如果暗能量是 宇宙命运 时间尺度
稳定的Λ(w=-1) 永远加速→“大冻结”(Big Freeze) ∞
慢慢增强的Λ(w逐渐<-1) “大撕裂”(Big Rip)——星系、行星、原子被撕裂 ~220亿年

真空衰变 量子隧穿到更稳定真空态→物理定律改变 任意时刻

当前共识：我们的数据最支持”大冻结”——宇宙将永远膨胀、冷却、变暗。最后黑矮星和黑洞也将蒸发。

练习三：哈勃张力意味着什么？（分析型）

两个独立方法测出的H₀差距5σ（~9%）。这不可能是巧合。请列出三种可能的解释。

点击查看参考答案

  1. 系统误差——某个测量有未被发现的偏误。但两个方法 都经过反复验证，5σ已极强。

  2. 新物理——暗能量不是常数Λ，而是随时间变化的精质。 早期和晚期宇宙的H₀不同是因为暗能量强度变了。

  3. 修正引力——广义相对论在宇宙尺度需要修正项。 早期和晚期宇宙的行为不同→推断出的H₀不同。

  4. 额外中微子/暗辐射——早期宇宙有额外的辐射成分， 可以调和两者。

目前(DESI 2024, ACT 2024)数据更加复杂——新的观测 似乎同时支持修正两边。这可能是当前宇宙学最大谜题。

练习四：暗能量的模拟假说假设（分析型）

如果你是模拟设计者，你在config里设置暗能量参数时，你会考虑什么？

点击查看参考答案

  1. 不能太强——宇宙太快膨胀→星系无法形成

  2. 不能太弱——宇宙可能坍缩→模拟提前结束

  3. 合适的”对冲”：抵消物质引力，但不用太快

  4. 最反直觉的动机：延迟热寂 宇宙=一个计算过程。如果所有物质聚在一起， 引力坍缩可能造成计算热点（类比CPU过热）。 慢慢散开会降低总体信息处理密度→平稳运行。

  5. 让”晚期宇宙”依然有可利用的自由能—— 避免全部物质变成黑洞然后蒸发。适度的暗能量 让宇宙”收敛到一个低温均匀状态”而非”灾难性崩溃”。

这当然是脑洞——但它在工程上逻辑自洽。

练习五：如果暗能量=0会怎样？（综合型）

假设爱因斯坦的”最大错误”是对的——暗能量根本不存在（Λ=0）。宇宙现在会是什么样？

点击查看参考答案

如果Λ=0，宇宙膨胀由物质密度决定： - 如果Ω_m > 1（超临界）：宇宙已开始坍缩 - 如果Ω_m = 1（平坦）：膨胀渐趋稳定 - 如果Ω_m < 1（亚临界）：继续膨胀但减速

当前观测：Ω_m ≈ 0.31 → 没有Λ的话应该是亚临界宇宙， 继续膨胀但永远减速。

关键差异： - 观测加速膨胀 → 需要Λ ≈ 0.69 - 没有Λ → 超新星应该比观测到的更亮， 而不是更暗

1998年的发现就是”比预期更暗的超新星”—— 如果Λ=0，这个结果不会出现。

爱因斯坦在1917年引入Λ是为了获得静态宇宙。 他说那是他的”最大错误”。但2011年诺奖说—— Λ是对的，只是原因不同。物理史充满了这种讽刺。
