一、纠缠到底”怪”在哪？——手套 vs 量子

1.1 经典关联（“手套模型”）

想象把左右两只手套分别放进两个盒子，随机送到北京和纽约。

条件 结论
你打开北京的盒子，看到左手套 你立刻”知道”纽约是右手套
这是超距作用吗？ 不是——手套在分离时就已经确定了

这就是经典关联：分离时就确定了，只是你不知道。

1.2 量子纠缠——为什么不是手套

经典手套 量子纠缠态
分离前 左右已确定 处于叠加态（未确定）
测量时 揭示已存在的值 创造值——不是揭示
测量结果相关性 100%（始终相反） 100%（如果测量同一方向）
能否解释为”分离时就确定”？ ✓ 能 ✗ 不能——贝尔不等式证明了这一点

1.3 EPR悖论：爱因斯坦的最后抵抗

1935年，爱因斯坦、波多尔斯基和罗森（EPR）发表论文，论证量子力学不可能是”完备的”理论：

EPR论证 内容
如果两个粒子纠缠 测量A立刻告诉你B的值
如果A和B足够远 信息传播需要时间→不能是”测量创造值”
结论 B的值一定在分离时就存在——只是量子力学没有描述它们

爱因斯坦称之为”鬼魅般的超距作用”（spooky action at a distance）。

EPR认为：量子力学不完整——存在我们还不知道的”隐变量”（hidden variables），它们预先决定了所有测量结果。

二、贝尔不等式：1964年的判决书

2.1 约翰·贝尔的猜想

北爱尔兰物理学家约翰·贝尔（1964）提出了一个绝妙的检验方法：

如果隐变量存在（如EPR所信），那么关联强度的统计分布必须满足一个不等式。而量子力学预言这个不等式会被违反。

2.2 贝尔不等式的简化版：CHSH

克劳泽、霍恩、希莫尼和霍尔特（1969）将贝尔不等式转化为可操作的实验形式：

S = E(a,b) - E(a,b') + E(a',b) + E(a',b')

其中 E(x,y) = Alice测x方向、Bob测y方向的相关函数

局域实在论：   |S| ≤ 2
量子力学：     |S| ≤ 2√2 ≈ 2.828
角度组合 纠缠态预测 E CHSH贡献
a,b: 0°, 22.5° -cos(22.5°) = -0.924 E(a,b)
a,b’: 0°, 67.5° -cos(67.5°) = -0.383 -E(a,b’)
a’,b: 45°, 22.5° -cos(22.5°) = -0.924 E(a’,b)
a’,b’: 45°, 67.5° -cos(22.5°) = -0.924 E(a’,b’)
S合计 -2.828

|S| ≈ 2.828 > 2 → 贝尔不等式被违反 → 局域实在论不成立。

2.3 意味着什么：二选一的残酷判决

贝尔不等式告诉我们：你不能同时拥有以下三样东西：

放弃 保留 代表
实在性 局域性 哥本哈根（观测创造值）
局域性 实在性 玻姆力学（超距作用）
两者都放弃 超级决定论 自由意志是幻觉

核心结论：量子力学不是”不完整”——它是不兼容。你不能用经典直觉来”补全”它而不破坏另一个经典直觉（局域性或实在性）。

四、纠缠与信息：不是超光速通信

4.1 为什么不能用来发消息

误解 事实
“我测量A，B立刻知道→超光速通信！” Alice不能控制她得到什么结果——结果是随机的
“我可以改变Bob的结果” Alice的测量结果是随机的，她无法编码信息
“量子纠缠=心灵感应” 纠缠=相关性，不是因果 
无通信定理（No-communication theorem）：
Alice的局域测量不能改变Bob能观测到的任何统计量。
Bob看到的结果分布始终是随机的——除非他收到
Alice通过经典信道发送的测量结果。
纠缠的用途 说明
量子密钥分发（QKD） 检测窃听——不是发送信息
量子隐形传态 传递量子态——但需要经典通信辅助
量子计算 纠缠=计算资源，不是通信手段

4.2 模拟假说视角：共享指针

如果纠缠不是”通信”，它是什么？

计算模型 量子纠缠对应
两个变量指向同一个内存地址 共享指针
两个对象共享同一个随机种子 伪随机同步
分布式系统的共享状态 副本一致性

工程直觉：“如果你在设计一个模拟系统，你不会真的让信息在两个远距离粒子之间’飞过去’——你会让它们共享同一个底层状态。纠缠可能就是这种共享——不是在空间里传递，而是在代码层共享同一个数据源。”

但在代码空间中，“超距作用”是日常操作——一个全局变量可以在任何地方被访问。

物理直觉 软件工程现实

练习一：经典关联 vs 量子纠缠（概念型）

Alice和Bob各分到一个”魔法硬币”。每个硬币有两面（A面和B面）。如果两人掷同一面（都选A或都选B），结果总是一正一反；如果不同面，则完全随机。请解释为什么这不能用”分离前就定好了”来解释。

点击查看参考答案

如果分离前所有结果就定好了，Alice的硬币需要同时满足： - 如果Bob选A→Alice是反面（与Bob相反） - 如果Bob选B→Alice是反面（与Bob相反）

但Alice也得满足： - 如果Bob选A→Alice正面 - 如果Bob选B→Alice正面

矛盾——因为Alice的硬币只有两面，不可能在”Bob选A” 和”Bob选B”两种情况下都给出相同的结果，除非Alice的结果 依赖于Bob的选择——但这是局域性不允许的。

这就是CHSH游戏的核心：经典策略成功率≤75%， 量子策略（使用纠缠态）成功率≈85%。 20个百分点的差距就是贝尔不等式的”判决空间”。

练习二：CHSH计算（计算型）

基于课文中给出的角度（a=0°, a’=45°, b=22.5°, b’=67.5°），验证CHSH值 S=-2.828 的计算过程。

点击查看参考答案

对于最大纠缠态 (|01⟩-|10⟩)/√2，相关函数 E(θ) = -cos(θ)

E(a,b) = -cos(22.5°) = -0.92388 E(a,b’) = -cos(67.5°) = -0.38268 E(a’,b) = -cos(22.5°) = -0.92388 E(a’,b’) = -cos(22.5°) = -0.92388

S = E(a,b) - E(a,b’) + E(a’,b) + E(a’,b’) = -0.92388 - (-0.38268) + (-0.92388) + (-0.92388) = -0.92388 + 0.38268 - 0.92388 - 0.92388 = -2.38896 (取最精确值 -2√2 ≈ -2.828)

验证：|S| = 2.38896 ≈ 2.828 > 2 → 贝尔不等式被违反 → 局域实在论被排除

练习三：为什么不能超光速通信（思考型）

Alice和Bob共享1000对纠缠光子。Alice想通过测量她的光子向Bob发送”1”这个消息。她可以做到吗？如果能，怎么做？如果不能，为什么？

点击查看参考答案

不能。

Alice测量她的光子时，她得到结果”0”或”1”——但这是随机的。 她不能控制”这次得到0”还是”这次得到1”。

Bob测量他的光子时，他得到的结果与Alice高度相关—— 但他无法区分”与Alice的结果相关”和”随机序列”。

Bob要验证纠缠存在，需要Alice通过经典信道告诉他她的测量结果。

无通信定理（1978, Ghirardi-Rimini-Weber）严格证明： 量子纠缠不能用于超光速通信。

但纠缠可以用于： 1. 量子密钥分发——检测是否有第三方窃听 2. 量子隐形传态——在经典通信的辅助下传递量子态

练习四：对模拟假说的意义（分析型）

如果我们的宇宙是模拟的，贝尔不等式的违反（即非局域性）会更加自然。请从”软件工程”的角度解释：为什么”共享指针”比”超光速通信”更可能是一个模拟系统的实现方式？

点击查看参考答案

  1. 性能：共享指针是O(1)的取值操作；超光速通信需要处理延迟和因果律

  2. 一致性：在分布式系统中，保证两个远距离节点的数据 一致性需要复杂的共识协议。而共享同一个内存地址天然一致。

  3. 模拟的层级结构：如果”物理空间”是模拟的一个渲染输出， 那么空间中的”距离”在引擎层没有意义—— 两个”相距一光年”的粒子可能占据相邻的内存地址。

  4. 量子非局域性=暴露底层架构： 贝尔不等式的违反可能是模拟系统的一个”泄露”—— 就像视频游戏的穿模bug泄露了碰撞体的实际几何形状。

  5. 经济性：任何工程师在设计大规模模拟时， 都会选择共享状态而非让信息在模拟空间中”飞”—— 后者不仅慢，还容易出现同步错误。

练习五：你的立场（综合型）

贝尔不等式排除局域实在论后，你需要放弃”局域性”或”实在性”之一。请说明你选择放弃哪一个，并解释你的选择如何影响你对”宇宙本质”的理解。

点击查看参考答案

选择放弃局域性（保留实在性） → 玻姆力学/全局隐变量路径 - 粒子有确定的位置和动量——即使我们测不准 - 存在一个”导引波”（pilot wave），瞬穿整个宇宙 - 代价：放弃物理直觉中的”信息最快光速传播” - 模拟假说解读：导引波=全局游戏状态变量

选择放弃实在性（保留局域性） → 哥本哈根/QBism路径 - 未测量的属性不”存在” - 测量不是发现而是创造 - 代价：放弃”客观世界独立于观测者” - 模拟假说解读：测量=触发渲染，叠加态=未渲染

选择超级决定论（两者都放弃） → 自由意志是幻觉 - 我们的”选择测量方向”也不是自由的 - 一切包括实验者的决定都是前定的 - 代价：我们无法信任科学实验的有效性 - 模拟假说解读：整个宇宙是确定性程序

三条路通向迥异的宇宙观。你选哪条？
